Import

One word per line: Word | note | alias, alias | tag, tag
Everything after the word is optional. Aliases and tags are separated by commas only, so a tag can contain spaces: easy maps is one tag. A full JSON export also works.
Importing only ever adds. Words already in the list are skipped, nothing is overwritten and nothing is removed.

Export

Export gives you the full JSON, including disabled words.

Keep a copy before a big edit. Nothing in this tab can destroy the list: import only adds. To undo a bad edit, delete the offending words in the Words tab and import your backup back in.

Words with no picture are matched against the shipped unit database by name. This runs on every restart, and you can run it now.
